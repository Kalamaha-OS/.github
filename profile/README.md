**Kalamaha** is an experimental rock collective and "soundtrack project" based in Rio de Janeiro and Sao Paulo, Brazil

---

## 📜 About the Project

Kalamaha began as a series of experimental recordings in a studio dubbed "the haunted house." It has since evolved into a full universe IRL, online, onchain.

## 🛠 Tech Stack (Gear)

The sound is built using the following dependencies:

* **Electric Frameworks:** Electric & Acoustic Guitars
* **Jaguar Bass:** Fender Jazzbass
* **Low-End Theory:** Sonor Drums
* **Rhythm Libraries:** Percussion
* **Wind Instruments:** Harmonica
* * **Synth Layers:** Roland Gaia
* **Audio Engine:** Himalayas Records Studio
